# Muma Bank Kubernetes Platform v1.0.0

The first stable portfolio release brings the full Muma Bank learning platform together: application engineering, container delivery, local Kubernetes, infrastructure as code, persistent data, ingress, security, CI, observability, troubleshooting, and operations.

## Highlights

- A polished Flask banking interface and API backed by transaction-safe PostgreSQL transfers.
- A reproducible three-node kind environment managed locally with Colima.
- Terraform-managed application infrastructure with persistent storage and generated credentials.
- Loopback-only ingress, restricted workloads, narrow network-policy intent, and secret scanning.
- Prometheus metrics, Grafana visualization, alert rules, and four failure-recovery labs.
- Five required GitHub Actions checks plus documentation validation in the shell job.

## Validation

The release candidate must pass:

- 31 application tests with at least 90% coverage
- Ruff, Bash syntax, and ShellCheck
- Terraform formatting, initialization, and validation
- local Markdown-link and release-metadata validation
- Gitleaks secret scanning
- Trivy container scanning for fixable high and critical vulnerabilities

## Known limitations

- The platform is local and educational; it is not a production banking system.
- PostgreSQL has one replica and node-local storage, so it is not highly available.
- Monitoring history is ephemeral.
- The preserved kindnet CNI does not enforce the documented NetworkPolicies.
- HTTPS, external backups, and external alert delivery are outside v1.0.0.
